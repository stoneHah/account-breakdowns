# 关键帧说明

这三张联系表由公开抖音作品的静帧拼成，用来和观看记录交叉核验。它们不是本档案的原创视觉作品。画面里的角色造型、字幕、地图和标题都来自原作品，权利归原作者「小qu档案馆」及所在平台。

本仓库没有用 MIT 或其他许可证把这些画面再授权出去。引用时请回到原作品。
